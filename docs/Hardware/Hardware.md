# Hardware

## Overview

This section documents the hardware used in the autonomous vehicle platform,
including system architecture, power distribution, wiring, and device-specific
configuration.

## Hardware Architecture

The hardware architecture describes the physical components, their connections,
communication interfaces, and power distribution.

See [Hardware Architecture](HardwareArchitecture/README.md).

## VESC Configuration

The VESC configuration documents the motor controller settings, including
current limits, voltage limits, CAN configuration, and application settings.

See [VESC Settings](VESC_setting/README.md).
